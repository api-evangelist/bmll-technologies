# BMLL Technologies

> BMLL is a London-based provider of harmonised historical Level 3, 2, and 1 order book data and analytics for capital markets, covering global equities, ETFs, futures, and options. Data is delivered through the BMLL Data Lab hosted Python environment, the BMLL Data Feed file product, and entitlement-gated REST APIs documented publicly via the official `bmll` Python SDK on PyPI. Access is sales-led (no self-serve signup); authentication uses per-account key-pair credentials (signed-JWT handshake, Bearer token).

Generated by API Evangelist (method: generated) from the apis.yml catalog and repo artifacts on 2026-07-22 — BMLL publishes no llms.txt of its own (probed: SPA shell / 403).

## APIs

- [BMLL Reference Data API](https://pypi.org/project/bmll/): Instruments, listings, and markets in the BMLL universe, with availability by data type and ETF constituents. Base: https://reference.data.bmlltech.com (403 without entitled credentials).
- [BMLL Time-Series API](https://pypi.org/project/bmll/): Daily metrics and analytics from harmonised Level 3 order book history, including classified trades. Base: https://time-series.data.bmlltech.com (403 without entitled credentials).
- [BMLL Market Data API](https://pypi.org/project/bmll/): Per-instrument market state and consolidated best bid/offer (CBBO) with an async poll-for-result pattern. Base: https://market-data.data.bmlltech.com (403 without entitled credentials).
- [BMLL APIv2 Query API](https://pypi.org/project/bmll/): Async dataset queries (initiate, poll, download JSONL/Arrow into pandas/polars). Base: https://api.data.bmlltech.com — its /openapi.json exists but returns 401 (entitlement-gated).

## Notes

- No public OpenAPI: https://api.data.bmlltech.com/openapi.json returns 401 Unauthorized; nothing was fabricated.
- Authentication: BMLL_USERNAME + PEM private key (BMLL_KEY_PATH, optional BMLL_KEY_PASSPHRASE) sign a JWT exchanged for a Bearer token; per-account entitlements and quotas apply.
- Rate limiting: HTTP 429; a body message of "Limit Exceeded" means the account quota is exhausted.
- Delivery channels beyond REST: S3 flat files, SFTP, and Snowflake shares.
- Compliance: ISO 27001 certified (https://www.bmlltech.com/news/our-news/bmll-awarded-iso-27001-certification).
